# Project Summary

## Recommended repository name

**adult-income-autoencoder-data-imputation**

This name is hiring-manager-friendly because it clearly communicates real-world tabular data, autoencoder modeling, missing-data imputation, PyTorch/ML engineering, and familiarity with the Adult Income dataset.

## Alternative names

- `tabular-autoencoder-data-imputation`
- `uci-adult-missing-data-autoencoder`
- `pytorch-tabular-imputation-autoencoder`
- `autoencoder-categorical-imputation`

## GitHub short description

PyTorch autoencoder for missing categorical-value imputation on the UCI Adult Income dataset, with preprocessing, masking, hyperparameter tuning, and baseline comparison.

## Resume bullets

- Developed a PyTorch autoencoder for categorical data imputation on the UCI Adult Income dataset, implementing preprocessing pipelines for missing-value removal, min-max scaling, one-hot encoding, masked feature reconstruction, and test-set evaluation.
- Outperformed a most-common-category baseline by ~20 percentage points, improving categorical imputation accuracy from ~45.7% to ~65.5%.
